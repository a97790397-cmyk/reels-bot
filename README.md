# ReelsArabi 🎬 منظومة إعلانات الفيديو المؤتمتة

بوت تيليجرام يستقبل طلبات الإعلانات، يولّد الفيديو بالذكاء الاصطناعي على Kaggle مجاناً، يضيف النصوص العربية أو الإنجليزية، يرسل المعاينة للعميل، ينفذ التعديلات، ويتحقق من دفع USDT تلقائياً ويسلّم الإعلان النهائي. كل هذا يشتغل على GitHub بدون ما يكون جهازك شغّالاً.

---

## كيف تشتغل؟

1. العميل يكلّم البوت: يكتب وصف المنتج، ويرسل صورته (اختياري)، ويختار اللغة والمدة.
2. كل ٥ دقائق، GitHub يشغّل "المدير" اللي يرسل الطلبات لـ Kaggle.
3. Kaggle يكتب سكربت الإعلان بنموذج لغة (Qwen)، ويولّد المقاطع بنموذج الفيديو (Wan 2.1).
4. المدير يدمج المقاطع ويحط النصوص وبطاقة النهاية بصورة المنتج، ويرسل **معاينة بعلامة مائية** للعميل.
5. العميل يختار: ✅ ممتاز، أو 🔄 إعادة توليد، أو ✏️ تعديل (يكتب وش يبغى يتغير).
6. لما يضغط ممتاز: يجيه مبلغ الدفع بالضبط وعنوان محفظتك. أول ما توصل الدفعة، يوصله الإعلان النظيف تلقائياً.
7. **أول إعلان لكل عميل مجاني**، ويوصل بشعار صغير في الزاوية.

ونسخة من كل إعلان نهائي توصلك أنت بصمت على تيليجرام.

---

## خطوات التشغيل (مرة وحدة، حوالي ٢٠ دقيقة)

### ١. سوِّ المستودع
1. ادخل GitHub واضغط **+** فوق، ثم **New repository**.
2. الاسم: `reels-bot`
3. اختر **Public**. هذا مهم: المستودعات العامة تشغيلها مجاني بلا حدود. ولا تقلق، كل بيانات العملاء **مشفّرة** ومفاتيحك في Secrets، فما أحد يقدر يشوف شي.
4. اضغط **Create repository**.

### ٢. ارفع الملفات
1. في صفحة المستودع الجديد، اضغط **uploading an existing file**.
2. فك ضغط ملف `reels-bot.zip` على جهازك، وادخل المجلد.
3. **حدد كل اللي داخله** (بما فيها مجلد `.github`) واسحبه لصفحة GitHub.
4. انتظر لين يخلص الرفع، واضغط **Commit changes**.
5. تأكد إن الملف `.github/workflows/bot.yml` موجود في المستودع. لو مو موجود، ارفعه لحاله.

### ٣. حط المفاتيح السرية (Secrets)
في المستودع: **Settings** ثم **Secrets and variables** ثم **Actions** ثم **New repository secret**. أضف هذي الخمسة، كل واحد على حدة:

| الاسم (Name) | القيمة (Secret) |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |
| `OWNER_ID` | `1916665011` |
| `KAGGLE_USERNAME` | `sasasma14` |
| `KAGGLE_KEY` | افتح ملف `kaggle.json` بالمفكرة، وانسخ القيمة اللي بعد `"key":` (بدون علامات التنصيص) |
| `STATE_PASSWORD` | اخترع كلمة سر طويلة (١٦ حرفاً أو أكثر) **واحفظها عندك**. هي اللي تشفّر بيانات العملاء |

⚠️ لو غيّرت `STATE_PASSWORD` بعدين، البيانات القديمة ما تنفتح. فاحفظها.

### ٤. شغّل المنظومة
1. افتح تبويب **Actions** في المستودع. لو طلب تفعيل، اضغط **I understand… enable**.
2. اختر **reels-bot** على اليسار، ثم **Run workflow** ثم **Run workflow**.
3. بعد دقيقة، ادخل على التشغيل وتأكد إنه شغّال بدون خطأ أحمر.

من الحين، تشتغل لحالها كل ٥ دقائق.

### ٥. جرّب
افتح البوت **@ReelsArabiBot**، أرسل `/start`، وسوِّ طلباً تجريبياً. البوت يرد خلال ثوانٍ، والمعاينة توصل بعد ما يخلص Kaggle (أول مرة أبطأ، لأنه ينزّل النماذج).

## أوامر المالك (أنت بس)
أرسلها للبوت من حسابك:
- `/stats`: الإحصائيات والمبالغ المحصّلة وحالة Kaggle
- `/orders`: الطلبات المفتوحة
- `/markpaid 12`: تسليم الطلب رقم 12 يدوياً (لو العميل حوّل مبلغاً مختلفاً عن المطلوب)
- `/cancel 12`: إلغاء طلب
- `/help`: قائمة الأوامر

## تعديل الأسعار والإعدادات
افتح `config.json` في GitHub واضغط ✏️:
- `lengths`: المدد وأسعارها وعدد المشاهد
- `first_order_free`: أول إعلان مجاني (`true` أو `false`)
- `max_revisions`: عدد التعديلات المجانية لكل إعلان
- `inference_steps`: جودة وسرعة التوليد (أقل = أسرع)

## إضافة حساب Kaggle ثاني (حساب أختك)
أختك تضيف بنفسها Secret باسم `KAGGLE_USERNAME_2` واسم المستخدم حقها، و`KAGGLE_KEY_2` ومفتاحها. والمنظومة توزّع الشغل على الحسابين تلقائياً.

## خيار: قناة تخزين
لو ما تبغى نسخ الإعلانات توصلك في محادثتك مع البوت، سوِّ قناة خاصة، أضف البوت مشرفاً فيها، وحط رقم القناة في Secret اسمه `STORAGE_CHAT_ID`.
